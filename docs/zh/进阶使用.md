# 进阶使用

## Droidspaces TUI

RootFS 内置统一维护菜单，可安装/更新 Mesa、Hangover Wine、Wine 字体和 Anland 组件：

```bash
droidspaces-tui
# 别名：dstui 或 ds-tui
```

可从源码仓库运行安装器说明中的脚本。下载源、校验、缓存、组件更新和卸载行为详见[脚本目录说明](../../scripts/README.md#droidspaces-tui)。

## USB 设备管理

全部发行版都内置 [Droidspaces USB Manager](https://github.com/Yizhou147/Droidspaces-USB-Manager)。在 Droidspaces 中为容器开启硬件访问后，可从应用菜单启动，或在 KDE 中运行：

```bash
usb-manager
```

也提供 `usb-passthrough` 和 `usb-storage-passthrough` 命令。安装与更新细节见[脚本说明](../../scripts/README.md#usb-manager-安装器)。

## 安装硬件固件

Debian 13 和 Ubuntu 24/25/26 镜像包含 `download-firmware`。在容器中按需手动运行：

```bash
sudo download-firmware
```

该工具不会在构建或启动时自动执行，依赖与处理细节见[脚本说明](../../scripts/README.md#固件工具)。

## 本地构建

本地构建需要 Docker、Docker Buildx 和 `xz`。跨架构构建还需要可用的 QEMU/binfmt 环境。

原生架构示例：

```bash
chmod +x build_rootfs-native.sh
./build_rootfs-native.sh \
  -i Debian-13.Dockerfile -v local -K KDE -L true \
  -B x11 -P socket -g true -a false -b true -c true \
  -d false -e true -f false -h false -n false \
  -S false -t false -u Gold
```

使用 QEMU 构建 ARM64 示例：

```bash
chmod +x build_rootfs-qemu-aarch64.sh
./build_rootfs-qemu-aarch64.sh \
  -i Ubuntu-26.Dockerfile -v local -K KDE -L true \
  -B anland-wayland -P none -g true -a false -b true -c true \
  -d false -e true -f false -h true -n true \
  -S false -t false -u Gold
```

产物名称类似 `Ubuntu-26-kde-Wayland-Droidspaces-rootfs-aarch64-local.tar.xz`。命令行参数由短选项指定；完整参数与映射关系可在 `build_rootfs-native.sh` 或 `build_rootfs-qemu-aarch64.sh` 文件开头查看。

## 已知限制

- Wayland/Anland 支持 Debian 13、Ubuntu 26、Fedora 43/44 和 Arch；Arch KDE 仅支持 Wayland，Ubuntu 24/25 使用 X11。
- GNOME 支持 Debian 13、Ubuntu 26、Fedora 43/44 和 Arch Linux ARM 的 Anland Wayland 构建。
- KDE Mobile 与 Anland Next 仅在支持 Wayland 的目标中提供。
- Niri、Hyprland、Mango 和 Denial 支持 Debian 13、Ubuntu 26、Fedora 43/44 和 Arch Linux ARM 的 Anland Wayland 构建。
- Fedora 某些设备需要开启硬件访问；Debian/Ubuntu 在禁用 `noseccomp` 或宿主内核缺少 `USER_NS` 时可能卡顿。
- Arch 当前不建议使用本项目的 QEMU/binfmt 跨架构方案。

Anland 桌面软件包在单独的 [`droidspaces-package`](https://github.com/Goldzxcbug/droidspaces-package) 仓库维护。项目依赖与鸣谢见[主页](../../README.md#致谢)。

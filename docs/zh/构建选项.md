# 构建选项

在 GitHub Actions 的 `Run workflow` 页面选择目标、桌面、显示后端和附加功能。带有桌面环境的 RootFS 面向 ARM64 Droidspaces 容器。

## 发行版与桌面支持

| 构建目标 | 基础镜像 | 可选桌面 | Anland Wayland |
| --- | --- | --- | --- |
| `Debian-13` | Debian 13 (trixie) | `none`、`KDE`、`KDE mobile`、`GNOME`、`Anland Next`、`Niri`、`Hyprland`、`Mango`、`Denial` | 支持 |
| `Ubuntu-24` | Ubuntu 24.04 | `none`、`KDE` | 不支持 |
| `Ubuntu-25` | Ubuntu 25.10 | `none`、`KDE` | 不支持 |
| `Ubuntu-26` | Ubuntu 26.04 | `none`、`KDE`、`KDE mobile`、`GNOME`、`Anland Next`、`Niri`、`Hyprland`、`Mango`、`Denial` | 支持 |
| `Fedora-43` | Fedora 43 | `none`、`KDE`、`KDE mobile`、`GNOME`、`Anland Next`、`Niri`、`Hyprland`、`Mango`、`Denial` | 支持 |
| `Fedora-44` | Fedora 44 | `none`、`KDE`、`KDE mobile`、`GNOME`、`Anland Next`、`Niri`、`Hyprland`、`Mango`、`Denial` | 支持 |
| `Arch` | Arch Linux ARM | `none`、`KDE`、`KDE mobile`、`GNOME`、`Anland Next`、`Niri`、`Hyprland`、`Mango`、`Denial` | 支持（KDE 仅 Anland Wayland） |

`all` 根据桌面与后端能力筛选并构建可用目标。`all-wayland` 为 KDE/KDE Mobile、GNOME、Niri、Hyprland、Mango 和 Denial 构建 Debian 13、Ubuntu 26、Fedora 43/44 与 Arch 五种 Wayland 目标。Arch KDE、GNOME、KDE Mobile、Anland Next、Niri、Hyprland、Mango 和 Denial 会强制使用 `anland-wayland`。

| 桌面 | 用途与说明 |
| --- | --- |
| `none` | 仅命令行环境，适合 SSH、开发或自行安装桌面。 |
| `KDE` | KDE Plasma 桌面；Arch 仅支持 Anland Wayland，其他支持目标可使用 X11 或 Anland Wayland。 |
| `KDE mobile` | 面向手机屏幕和触控的 Plasma Mobile，会强制启用 Anland Wayland。 |
| `GNOME` | Debian 13、Ubuntu 26、Fedora 43/44 和 Arch Linux ARM 的完整 Anland Wayland 桌面，不支持 X11。包含终端、文件管理器、设置、系统监视器、密钥环、门户和常用文档/媒体应用。 |
| `Anland Next` | 提供 Anland 会话、rootless Xwayland 与 mini-wm，不包含完整桌面环境；仅支持 Anland Wayland。 |
| `Niri`、`Hyprland`、`Mango`、`Denial` | Debian 13、Ubuntu 26、Fedora 43/44 和 Arch Linux ARM 上的 Anland Wayland 合成器。提供基础终端、XDG portal、音频和字体服务，不预装完整桌面应用。 |

## 工作流输入

| 输入 | 可选值 / 默认值 | 说明 |
| --- | --- | --- |
| `build_target` | 发行版、`all`、`all-wayland`；默认 `Debian-13` | 选择构建目标。 |
| `custom_username` | 1–32 位字母、数字、`_`、`-`；以字母或 `_` 开头；默认 `Gold` | RootFS 普通用户名称。 |
| `desktop` | `none`、`KDE`、`KDE mobile`、`GNOME`、`Anland Next`、`Niri`、`Hyprland`、`Mango`、`Denial`；默认 `KDE` | 选择桌面或命令行环境。 |
| `desktop_autostart` | `true` / `false`；默认 `true` | 安装桌面自启动服务；`none` 必须关闭。 |
| `display_backend` | `x11` / `anland-wayland` | 中文工作流默认 Wayland，英文工作流默认 X11；Arch KDE 及其他部分桌面会强制使用 Wayland。 |
| `PulseAudio` | `socket` / `tcp` / `none`；默认 `socket` | X11 音频转发方式；Anland 会自动设为 `none`。 |
| `enable_zh_tz` | `true` / `false` | 安装中文 locale 并设置上海时区；中英文工作流默认值不同。 |
| `enable_mesa` | `true` / `false`；默认 `true` | 添加 Snapdragon GPU/Mesa 支持。 |
| `enable_8gen2_wayland` | `true` / `false`；默认 `false` | 为相关设备设置 Turnip UBWC Wayland 修复参数。 |
| `nosnap` | `true` / `false` | 仅 Ubuntu：移除 Snap、snapd 并阻止其被 APT 重新安装；中英文工作流默认值不同。 |
| `enable_systemd257` | `true` / `false`；默认 `false` | 在旧 Android 内核场景尝试安装 systemd 257 包族；只支持 `none` 和普通 `KDE`。 |
| `enable_srf` | `true` / `false` | 安装 Fcitx5；中文工作流默认开启，英文工作流默认关闭。 |
| `enable_binfmt` | `true` / `false`；默认 `false` | 添加 binfmt 跨架构支持；当前不建议用于 Arch。 |
| `enable_yj` | `true` / `false`；默认 `true` | 增强 NAT 与 Android/Droidspaces 硬件识别。 |
| `enable_kfgj` | `true` / `false`；默认 `false` | 安装编译器、CMake、Python 等开发工具。 |
| `enable_zip` | `true` / `false`；默认 `true` | 安装常用压缩工具。 |
| `enable_docker` | `true` / `false`；默认 `false` | 在 RootFS 中安装 Docker 相关软件包。 |
| `wayland_package_repository` | 公开的 `owner/repository`；默认 `Goldzxcbug/droidspaces-package` | 指定预编译 Anland 软件包 Release 的来源。 |

完整的 workflow 默认值可在 `.github/workflows/build-rootfs-releases.yml`（中文）和 `build-rootfs-releases-en.yml`（英文）中查看。`enable_systemd257` 属于实验性旧内核兼容选项，会增加构建时间；systemd 已为 257 或更低版本的系统会跳过安装，详见[脚本说明](../../scripts/README.md)。

## 自动生成的 Droidspaces 推荐配置

原生和 QEMU 构建都会按最终生效的选项生成 `container.config`，将其作为归档的第一个
普通文件，再写入 rootfs 内容并压缩为 XZ。原包中的旧同名配置会被移除，无需在
Dockerfile 中另加 `COPY`。支持推荐配置的 Droidspaces 安装向导会自动载入这些值。

| 构建选项 | 推荐配置 |
| --- | --- |
| `anland-wayland` | `enable_anland=1`，关闭 Termux:X11 和 PulseAudio |
| `x11` | `enable_termux_x11=1`，关闭 Anland |
| X11 且音频为 `socket` | `enable_pulseaudio=1`，其他音频选择为 `0` |
| KDE 或 KDE Mobile | `allow_userns=1` |
| 安装 Docker | `net_mode=nat`，未选择时沿用 app 默认值 |
| 开启高通骁龙 GPU 支持 | `enable_gpu_mode=1` |
| Anland Next | `bind_mounts=/data/local/tmp/awl:/run/anland` |
| `enable_zh_tz=true`（启用中文 locale 和上海时区） | `dns_servers=114.114.114.114` |

字段名沿用 Droidspaces 的 Anland 分支。挂载路径仅写入配置，由 Droidspaces 已有的
`bind_mounts` 解析和挂载流程处理。环境变量不通过这份推荐配置传递。KDE 的用户命名
空间选项在不支持的内核上保持推荐的开启显示，但开关灰显，不表示内核提供了该功能。

本地验证配置映射和打包顺序：`python3 -m unittest discover -s tests -v`。

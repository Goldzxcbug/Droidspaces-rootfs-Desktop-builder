# 快速开始

## 订阅固定全桌面 RootFS

在 Droidspaces 的 RootFS 仓库管理中添加所需语言的订阅源：[中文 RootFS（GitHub）](https://github.com/Goldzxcbug/Droidspaces-rootfs-Desktop-builder/releases/download/droidspaces-rootfs-all-wayland/rootfs_zh.json)、[中文 RootFS（CNB）](https://cnb.cool/goldzxcbug/droidspaces-package/-/releases/download/droidspaces-rootfs-all-wayland/rootfs_zh.json) 或 [English RootFS（GitHub）](https://github.com/Goldzxcbug/Droidspaces-rootfs-Desktop-builder/releases/download/droidspaces-rootfs-all-wayland/rootfs_en.json)。GitHub 和 CNB 中的中文索引分别使用对应源的 RootFS 下载地址；该滚动源每周自动更新，包含 Debian 13、Ubuntu 26、Fedora 43/44 和 Arch 上的全部 Anland Wayland 桌面。

## 1. 在 GitHub Actions 构建

1. Fork 本仓库到自己的 GitHub 账号，并打开仓库的 `Actions` 页面。
2. 选择“编译并发布 Droidspaces RootFS”，点击 `Run workflow`。
3. 选择发行版、桌面、显示后端和所需功能，然后启动工作流。
4. 等待工作流完成，在 `Releases` 页面下载生成的 `.tar.xz` 文件。

常见的 Wayland 配置为 Debian 13、Ubuntu 26、Fedora 43/44 或 Arch，桌面选择 `KDE`，显示后端选择 `anland-wayland`。首次使用可保留默认参数；Ubuntu 用户可按需启用或关闭 `nosnap`。不同语言工作流的部分默认值不同，完整说明见[构建选项](构建选项.md)。

Wayland 构建使用 `Goldzxcbug/droidspaces-package` 中发布的 patched 桌面组件。若使用自己的包仓库，在 `wayland_package_repository` 填写公开的 `owner/repository`，且该仓库应发布对应的 Anland 软件包 Release。

## 2. 导入 Droidspaces

在 Droidspaces 中创建或导入容器，将下载的 `.tar.xz` 设为 RootFS。桌面镜像需要在容器设置中开启硬件访问。

- Debian/Ubuntu 建议在特权模式中启用 `noseccomp`，并确认宿主内核启用了 `USER_NS`，否则桌面操作可能卡顿。
- Fedora 在部分设备上需要开启硬件访问，否则可能闪屏或崩溃。
- X11 桌面需要准备 Termux:X11。
- Anland Wayland 还需要完成[宿主端配置](桌面与Anland.md#wayland-和-anland-宿主端配置)。

## 3. 首次启动

若构建时启用了 `desktop_autostart`，容器启动后会由 `desktop-session.service` 启动桌面。否则，使用普通用户登录后按桌面执行启动命令，详见[桌面启动说明](桌面与Anland.md)。

RootFS 默认用户为 `Gold`，默认密码为 `1234`（如果构建时修改了用户名，则使用自定义用户名）。首次登录后请立即修改密码：

```bash
passwd
```

> `all` 和 `all-wayland` 可一次构建多个兼容目标；GNOME、Niri、Hyprland、Mango 和 Denial 支持 Debian 13、Ubuntu 26、Fedora 43/44 与 Arch Linux ARM。矩阵与限制见[构建选项](构建选项.md)。
